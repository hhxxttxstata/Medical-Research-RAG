# 医学影像 AI 系统部署运维手册

## 1. 环境要求

### 1.1 硬件要求
- CPU：Intel Xeon Gold 或同等性能，16 核以上
- 内存：64 GB 以上
- GPU：NVIDIA A100 / V100 / RTX 4090，显存 24 GB 以上
- 存储：SSD 1TB 以上
- 网络：千兆以太网

### 1.2 软件要求
- 操作系统：Ubuntu 22.04 LTS / CentOS 7.9+
- Docker：24.0.0+
- Docker Compose：2.20.0+
- NVIDIA Driver：545.23.08+
- NVIDIA Container Toolkit：1.14.0+

## 2. 部署步骤

### 2.1 Docker 部署（推荐）

```bash
# 克隆项目仓库
git clone https://github.com/example/medical-image-ai.git
cd medical-image-ai

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件，修改数据库密码等配置

# 一键启动
docker-compose up -d

# 检查服务状态
docker-compose ps
```

### 2.2 Kubernetes 部署

```bash
# 创建命名空间
kubectl create namespace medical-ai

# 部署 ConfigMap
kubectl apply -f k8s/configmap.yaml

# 部署各服务
kubectl apply -f k8s/deployment.yaml
kubectl apply -f k8s/service.yaml

# 部署 Ingress
kubectl apply -f k8s/ingress.yaml
```

## 3. 服务组件说明

| 服务名 | 端口 | 说明 |
|-------|------|-----|
| api-gateway | 8080 | API 网关，统一入口 |
| preprocess | 8081 | 影像预处理服务 |
| detection | 8082 | 病灶检测服务 |
| segmentation | 8083 | 分割服务 |
| minio | 9000 | 影像文件存储 |
| postgres | 5432 | 结构化数据存储 |

## 4. 监控与告警

### 4.1 Prometheus 指标
系统暴露以下 Prometheus 指标：
- `ai_inference_latency_ms`：推理延迟（毫秒）
- `ai_inference_count_total`：推理请求总数
- `ai_inference_error_total`：推理错误总数
- `gpu_memory_usage_bytes`：GPU 显存使用量

### 4.2 日志管理
日志采用 JSON 格式输出，通过 Filebeat 采集到 Elasticsearch 集群，使用 Kibana 进行可视化查询。

## 5. 常见问题处理

### 5.1 GPU 不可用
检查 NVIDIA 驱动和 Container Toolkit 是否正确安装：
```bash
nvidia-smi
docker run --rm --gpus all nvidia/cuda:12.2-base nvidia-smi
```

### 5.2 磁盘空间不足
定期清理旧的日志文件和镜像：
```bash
docker system prune -af
```
