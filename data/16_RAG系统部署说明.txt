RAG 系统部署说明
===================

一、系统依赖
-----------
1. Python 3.10+
2. ChromaDB（向量数据库）
3. Sentence-Transformers（Embedding 模型）
4. OpenAI API 或兼容接口（大模型生成）

二、安装步骤
-----------
1. 创建虚拟环境
   conda create -n rag-system python=3.10
   conda activate rag-system

2. 安装依赖
   pip install chromadb sentence-transformers pypdf openai tiktoken python-dotenv

3. 配置环境变量
   创建 .env 文件，配置以下内容：
   OPENAI_API_KEY=your_api_key
   OPENAI_BASE_URL=https://api.openai.com/v1
   EMBEDDING_MODEL=BAAI/bge-small-zh-v1.5

三、运行方式
-----------
1. 初始化知识库
   python main.py --init

2. 启动交互式问答
   python main.py --query "你的问题"

3. 启动 Web 服务（可选）
   python web_app.py

四、目录结构
-----------
rag-system/
├── data/              # 文档存放目录
│   ├── *.md           # Markdown 文档
│   ├── *.txt          # 文本文件
│   └── *.pdf          # PDF 文件
├── chroma_db/         # 向量数据库存储目录
├── src/               # 源代码目录
│   ├── document_loader.py
│   ├── text_splitter.py
│   ├── embeddings.py
│   ├── vector_store.py
│   ├── retriever.py
│   ├── generator.py
│   └── rag_pipeline.py
├── main.py            # 主入口脚本
├── requirements.txt   # 依赖清单
└── .env               # 环境变量配置

五、注意事项
-----------
1. 首次运行需要下载 Embedding 模型，约 500MB
2. PDF 文档需要确保是文本型 PDF，扫描件需要 OCR 支持
3. 大模型 API 调用需要有效的 API Key
4. 向量数据库默认存储在 chroma_db/ 目录下
