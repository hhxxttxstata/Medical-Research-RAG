# 深度学习环境配置指南

## 1. Anaconda 环境配置

### 1.1 安装 Anaconda
从 https://www.anaconda.com/download 下载 Anaconda 最新版本，安装时勾选"Add Anaconda to PATH"选项。

### 1.2 创建虚拟环境
```bash
conda create -n medical-ai python=3.10
conda activate medical-ai
```

### 1.3 安装核心库
```bash
# 深度学习框架
pip install torch==2.1.0 torchvision==0.16.0 --index-url https://download.pytorch.org/whl/cu121

# 医学图像处理
pip install monai==1.3.0
pip install nibabel==5.2.0
pip install pydicom==2.4.3
pip install SimpleITK==2.3.0

# 图像处理
pip install opencv-python==4.9.0.80
pip install Pillow==10.2.0

# 数据科学
pip install numpy==1.26.3
pip install pandas==2.1.5
pip install scikit-learn==1.4.0
pip install matplotlib==3.8.2
```

## 2. NVIDIA 深度学习配置

### 2.1 驱动安装
1. 访问 NVIDIA 驱动下载页面：https://www.nvidia.com/drivers
2. 选择对应显卡型号的操作系统版本
3. 安装驱动后重启，运行 nvidia-smi 验证安装

### 2.2 CUDA 安装
CUDA 11.8 或 12.1 为推荐版本。安装后设置环境变量：
```bash
export PATH=/usr/local/cuda-12.1/bin:$PATH
export LD_LIBRARY_PATH=/usr/local/cuda-12.1/lib64:$LD_LIBRARY_PATH
```

### 2.3 cuDNN 安装
从 NVIDIA Developer 网站下载 cuDNN，将解压后的文件复制到 CUDA 安装目录：
```bash
cp cudnn-linux-x86_64-8.9.7.29_cuda12-archive/include/* /usr/local/cuda-12.1/include/
cp cudnn-linux-x86_64-8.9.7.29_cuda12-archive/lib/* /usr/local/cuda-12.1/lib64/
```

## 3. Docker 深度学习环境

使用官方 PyTorch Docker 镜像可快速搭建环境：
```bash
docker pull pytorch/pytorch:2.1.0-cuda12.1-cudnn8-devel
docker run --gpus all -it --name medical-ai-env \
  -v /data:/workspace/data \
  pytorch/pytorch:2.1.0-cuda12.1-cudnn8-devel
```
