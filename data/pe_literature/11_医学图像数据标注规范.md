# 医学图像数据标注规范

## 1. 标注目的

医学图像标注是为 AI 模型训练提供高质量的标注数据。规范的标注流程和标准化的标注格式是保证模型性能的基础。

## 2. 标注工具推荐

| 工具名称 | 支持平台 | 主要功能 | 是否免费 |
|---------|---------|---------|---------|
| ITK-SNAP | Windows/Linux/Mac | 医学图像分割标注 | 是 |
| 3D Slicer | Windows/Linux/Mac | 综合医学图像分析平台 | 是 |
| LabelMe | Web | 多边形、矩形标注 | 是 |
| CVAT | Web | 多种标注类型 | 是 |

## 3. 标注格式

### 3.1 目标检测标注
采用 DICOM-RDS 格式，每个病灶记录以下字段：
```
{
  "SOPInstanceUID": "1.2.840.10008.5.1.4.1.1.2",
  "FindingType": "Nodule",
  "bbox": [x, y, width, height],
  "probability": 0.95,
  "radiologist": "张三"
}
```

### 3.2 分割标注
分割标注采用 NIfTI 格式存储，每个分割掩膜为一个独立文件，与原始影像保持相同的空间分辨率和坐标系。

## 4. 标注流程

### 4.1 初标
由标注员使用标注工具逐层勾画病灶轮廓。对于肺结节，需在横断面、冠状面和矢状面三个视角分别确认。

### 4.2 复核
由资深放射科医生对初标结果进行复核，检查以下内容：
- 病灶边界是否准确
- 是否有遗漏的病灶
- 标注类别是否正确

### 4.3 终审
由科室主任对复核后的标注进行抽检，抽检比例不低于 20%。终审通过的数据方可入库用于模型训练。

## 5. 质量控制

### 5.1 一致性检验
定期对标注结果进行一致性分析，计算标注员间的 Kappa 系数，要求 Kappa 值大于 0.80。

### 5.2 常见标注错误
1. 边界标注过于宽松，将正常组织包含在内
2. 对磨玻璃结节（GGO）边界的判断不够精确
3. 漏标微小病灶（直径 < 5mm）
4. 不同标注员对同一病灶的类别判断不一致
